# ดัชนีตัวละคร (Character Index)

> ตัวละครแต่ละคนแยกเป็นไฟล์ของตัวเอง หาง่าย แก้ง่าย ไม่ต้องไล่อ่านไฟล์ยาวๆ
> เพิ่มตัวละครใหม่ = สร้างไฟล์ใหม่ในโฟลเดอร์นี้ แล้วเพิ่มแถวในตารางนี้

| ชื่อ | บทบาท | ไฟล์ |
|---|---|---|
| เฉินมู่ | ตัวเอก | [เฉินมู่.md](./เฉินมู่.md) |
| เฉินต้าสุ่ย | พ่อของตัวเอก | [เฉินต้าสุ่ย.md](./เฉินต้าสุ่ย.md) |
| หวังชิว | แม่ของตัวเอก | [หวังชิว.md](./หวังชิว.md) |
| เฉินเจี้ยน | พี่ชายคนโต | [เฉินเจี้ยน.md](./เฉินเจี้ยน.md) |
| เฉินหนิง | น้องสาวคนเล็ก | [เฉินหนิง.md](./เฉินหนิง.md) |
| จ้าวเหิง | หัวหน้าตระกูลจ้าว (ฝ่ายตรงข้าม) | [จ้าวเหิง.md](./จ้าวเหิง.md) |
| หลิวเฟิง | เพื่อนคนรับใช้ฝ่ายนอกรุ่นเดียวกัน | [หลิวเฟิง.md](./หลิวเฟิง.md) |
| ซูหว่าน | ผู้ดูแลหอตำราวิชาฝ่ายนอก | [ซูหว่าน.md](./ซูหว่าน.md) |

> พล็อตเดิมถูกยกเลิก ตัวละครเดิมทั้งหมด (เยี่ยหลิน, ซูอิงเยว่, อาจารย์ฮั่นชิง, เหยียนกวง, หลี่เฉิงหวาง) ไม่ใช้แล้ว ไม่มีไฟล์ของตัวละครเหล่านี้อีกต่อไป
