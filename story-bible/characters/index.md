# ดัชนีตัวละคร (Character Index)

> ตัวละครแต่ละคนแยกเป็นไฟล์ของตัวเอง หาง่าย แก้ง่าย ไม่ต้องไล่อ่านไฟล์ยาวๆ
> เพิ่มตัวละครใหม่ = สร้างไฟล์ใหม่ในโฟลเดอร์นี้ แล้วเพิ่มแถวในตารางนี้

| ชื่อ | บทบาท | ไฟล์ |
|---|---|---|
| เฉินมู่ | ตัวเอก | [เฉินมู่.md](./เฉินมู่.md) |
| เฉินต้าสุ่ย | พ่อของตัวเอก | [เฉินต้าสุ่ย.md](./เฉินต้าสุ่ย.md) |
| หวังชิว | แม่ของตัวเอก | [หวังชิว.md](./หวังชิว.md) |
| เฉินเจี้ยน | พี่ชายคนโต | [เฉินเจี้ยน.md](./เฉินเจี้ยน.md) |
| เฉินหนิง | น้องสาวคนเล็ก | [เฉินหนิง.md](./เฉินหนิง.md) |
| จ้าวเหิง | หัวหน้าตระกูลจ้าว (ฝ่ายตรงข้าม) | [จ้าวเหิง.md](./จ้าวเหิง.md) |
| หลิวเฟิง | เพื่อนคนรับใช้รุ่นเดียวกัน | [หลิวเฟิง.md](./หลิวเฟิง.md) |
| หลินเสวี่ย | ผู้อาวุโสหญิงนิกายเสวียนอวิ๋น ผู้เชี่ยวชาญกายาธาตุน้ำแข็ง | [หลินเสวี่ย.md](./หลินเสวี่ย.md) |
| หลี่เฉิน | ศิษย์สายตรง กายาธาตุไฟ (arc งานประลอง) | [หลี่เฉิน.md](./หลี่เฉิน.md) |
| ซุนเยี่ย | ศิษย์สายตรง กายาธาตุไม้ (arc งานประลอง) | [ซุนเยี่ย.md](./ซุนเยี่ย.md) |
| หยวนซิง | ศิษย์สายตรง กายาธาตุสายฟ้า (arc งานประลอง) | [หยวนซิง.md](./หยวนซิง.md) |
| เมิ่งเทียน | อาจารย์คนแรกของเฉินมู่ ผู้บำเพ็ญระดับสูง + พลังจิตกลายพันธุ์ | [เมิ่งเทียน.md](./เมิ่งเทียน.md) |
| อวิ๋นเยี่ย | ศิษย์พี่คนที่ 3 ของเมิ่งเทียน กายาธาตุลม + พลังกลายพันธุ์ควบคุมสภาพอากาศ | [อวิ๋นเยี่ย.md](./อวิ๋นเยี่ย.md) |
| ซูอิ่ง | ศิษย์พี่คนที่ 5 ของเมิ่งเทียน พลังกลายพันธุ์ทะลุผ่านวัตถุ | [ซูอิ่ง.md](./ซูอิ่ง.md) |
| เสี่ยวเป่า (小宝) | อดีตตัวร้ายตัวแรกของเฉินมู่ พลังกายภาพเหนือมนุษย์แบบ Lobo ปัจจุบันเป็นลูกน้อง/สมาชิกครอบครัวใหม่ | [เสี่ยวเป่า.md](./เสี่ยวเป่า.md) |
| ลี่เหิง (厉衡) | ศิษย์น้องร่วมอาจารย์ของเมิ่งเทียน ระดับบำเพ็ญใกล้เคียงกัน พลังกลายพันธุ์ควบคุมโลหะแบบ Magneto บทบาทเป็นกลาง/คลุมเครือ ยังไม่ปรากฏตัวจริง | [ลี่เหิง.md](./ลี่เหิง.md) |

> พล็อตเดิมถูกยกเลิก ตัวละครเดิมทั้งหมด (เยี่ยหลิน, ซูอิงเยว่, อาจารย์ฮั่นชิง, เหยียนกวง, หลี่เฉิงหวาง) ไม่ใช้แล้ว ไม่มีไฟล์ของตัวละครเหล่านี้อีกต่อไป
