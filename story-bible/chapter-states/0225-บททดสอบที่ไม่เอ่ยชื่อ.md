# สถานะตัวละคร — ตอนที่ 225: บททดสอบที่ไม่เอ่ยชื่อ

**เวลาในเรื่อง:** วันถัดมา ต่อเนื่องจากตอนที่ 224 Day ~2424 (เขียนใหม่ 2 ต.ค. 2569 — ชื่อเดิม "น้ำหนักที่แบกไว้คนเดียว")

## ตัวละครที่ปรากฏ

**เฉินมู่**
- ถูกไป๋เหิงทดสอบตลอดวัน รับมือได้สบายด้วยความคิดที่แบ่งทำงานเร็วกว่าแสง ไม่เหนื่อย: ชี้จุดชำรุดเฉพาะที่ตาเห็น / ตอบตามจริงว่าไม่เคยซ่อมยันต์ / แสดงความเข้าใจช้าลงครึ่งจังหวะและปล่อยมือสั่นตอนต่อเส้น / ไม่ตอบเรื่องยันต์ที่ไม่เคยถูกสอน / ไม่แก้คำไป๋เหิงเรื่องอายุยันต์กันความชื้น (รู้ว่าเริ่มอ่อนวันที่ยี่สิบห้า ไม่ใช่สามสิบ) / ปล่อยแผ่นยันต์รั่วไว้ในกองดี — สิ่งเดียวที่ยากคือการยืนดูข้อผิดพลาดเล็กๆ โดยไม่แก้ สัมผัสว่าความระวังของไป๋เหิงเหมือนคนที่เคยเจ็บมาก่อน จบวันด้วยความรู้สึกว่าทุกอย่างอยู่ในการควบคุม

**เสี่ยวเป่า**
- ฝึกท่าทางการต่อสู้ในห้องพัก ฟังเรื่องซ่อมยันต์ หัวเราะที่พี่มือสั่น ได้คำแนะนำเรื่องการวางเท้า มื้อเย็นปกติ ไม่สังเกตอะไรผิดปกติ

**ไป๋เหิง**
- ทดสอบเฉินมู่ทั้งวันโดยไม่บอกเหตุผล ความสงสัยผ่อนลงแต่ไม่หาย เพราะคำตอบถูกต้องเรียบร้อยเกินไป

## สถานที่

ร้านหมื่นสิ่ง, ห้องเช่า

## ตัวละครที่ไม่ปรากฏ / ไม่เปลี่ยนแปลงในตอนนี้

ชายชรา, ลุงเหวิน, เหอเซิง, เฉินหนิง, หลินเสวี่ย, เฉินต้าสุ่ย, หวังชิว, เฉินเจี้ยน, อวิ๋นเยี่ย, ซูอิ่ง, เมิ่งเทียน, ปู้เสวียน, ยฺเหวียนเฟิง, จ้าวเหิง — ไม่ปรากฏ
