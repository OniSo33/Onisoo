# ตอนที่ 200: ชื่อตอนว่า สิ่งที่ไม่เคยเปิดเผย

เช้าวันถัดมาเมื่อเฉินมู่มาถึงศาลเจ้าตามเวลาปกติ เขานั่งลงตรงจุดเดิมที่คุ้นเคยแล้ว เสี่ยวเป่านั่งข้างๆ กำลังพยายามต่อกิ่งไม้เล็กๆ ให้เป็นรูปสัตว์อย่างตั้งใจ

*วันนี้รู้สึกยังไงบ้าง* เฉินมู่ถามเหอเซิงด้วยความห่วงใยตามปกติ

*ดีมาก* เหอเซิงตอบด้วยน้ำเสียงสดใส *รู้สึกเบาสบายขึ้นเยอะเลยหลังจากได้ระบายทุกอย่างที่เก็บไว้คนเดียวมานานให้เจ้าฟัง*

เฉินมู่ยิ้มบางๆ ฟังคำตอบนั้นด้วยความรู้สึกที่ซับซ้อนกว่าที่แสดงออกมาทางสีหน้ามาก

ตลอดสิบสามวันที่ผ่านมา ตั้งแต่วินาทีแรกที่สัมผัสได้ถึงเจตนาของเหอเซิงที่ศาลเจ้าแห่งนี้ เขารู้ดีอยู่แก่ใจว่าตัวเองไม่ได้แค่ "สัมผัสได้" เพียงอย่างเดียวเหมือนที่ปล่อยให้เหอเซิงเข้าใจไปตลอด พลังจิตของเขาที่ผ่านการฝึกฝนอย่างหนักหน่วงในมิติมืดมานั้น เหนือกว่าพลังของเหอเซิงมากเกินกว่าจะเทียบกันได้เลย ทุกครั้งที่คุยกัน เขาแทรกซึมเข้าไปในกระแสความคิดของเหอเซิงเบาๆ อย่างแนบเนียน สร้างสภาวะที่ทำให้เหอเซิงตอบคำถามทุกอย่างตรงไปตรงมาโดยไม่มีการปิดบังหรือระแวดระวัง

เหอเซิงไม่เคยรู้ตัวเลยสักครั้ง เข้าใจไปเองว่าที่ตัวเองพูดทุกอย่างออกมาอย่างเปิดเผยขนาดนี้ เป็นเพราะความไว้ใจล้วนๆ ที่ก่อตัวขึ้นจากการสัมผัสเจตนาดีของเฉินมู่ตั้งแต่แรกเจอ

*ท่านจำได้ไหมว่าคุยอะไรกับข้าไปบ้างในวันแรกที่เจอกัน* เฉินมู่ถามขึ้นอย่างเป็นธรรมชาติ ทดสอบบางอย่างในใจ

เหอเซิงนิ่งไปครู่หนึ่ง ความรู้สึกที่ส่งมามีความสับสนเล็กน้อยแทรกอยู่ *จำได้คร่าวๆ นะ... เรื่องที่ข้าแนะนำตัว เล่าประวัติให้ฟัง... แต่มีบางช่วงที่รู้สึกเลือนลางแปลกๆ เหมือนความทรงจำบางส่วนหายไป*

เฉินมู่รู้สึกได้ถึงความจริงในคำพูดนั้น เป็นผลข้างเคียงที่เขาไม่ได้ตั้งใจให้เกิดขึ้นในตอนแรก แต่เมื่อพลังจิตที่ใช้ควบคุมอย่างต่อเนื่องนานสิบสามวันติดต่อกัน บางส่วนของความทรงจำที่ถูกสร้างภายใต้อิทธิพลนั้นย่อมเลือนหายไปเองตามธรรมชาติของสิ่งที่ไม่ใช่ความทรงจำที่แท้จริงร้อยเปอร์เซ็นต์

*แปลกจริงๆ* เหอเซิงพูดต่อ ไม่ได้สงสัยอะไรมากไปกว่านั้น *บางทีอาจจะเป็นเพราะข้าตื่นเต้นเกินไปตอนเจอเจ้าครั้งแรกก็ได้ เลยจำรายละเอียดได้ไม่ครบ*

เฉินมู่ไม่ได้แก้ต่างหรือปฏิเสธคำอธิบายนั้น ปล่อยให้เหอเซิงเชื่อไปตามที่คิดเอง

ในใจของเขา ความคิดเกี่ยวกับสิ่งที่ทำลงไปตลอดสิบสามวันที่ผ่านมาผุดขึ้นมาชัดเจน เขารู้ดีว่าตัวเองกำลังควบคุมจิตใจของเหอเซิงอยู่ ไม่ใช่แค่การสัมผัสรับรู้เฉยๆ อย่างที่ปล่อยให้เข้าใจไป แต่เป็นการแทรกแซงที่แนบเนียนจนไม่มีใครทันสังเกต

ทว่าความรู้สึกผิดที่ควรจะเกิดขึ้นกลับไม่มาเยือนเลยแม้แต่น้อย

เขานึกย้อนไปถึงความรู้สึกผิดอันลึกซึ้งที่เคยมีต่อการเข้าสิงร่างกายผู้อื่นโดยไม่ได้รับความยินยอมในอดีต เป็นความรู้สึกที่ฝังลึกจนเคยทำให้เขาลังเลใจอยู่นาน แต่ครั้งนี้ต่างออกไปโดยสิ้นเชิง ไม่มีร่างกายใครถูกล่วงล้ำ ไม่มีใครได้รับบาดเจ็บหรือเสียหายจากสิ่งที่เขาทำ เหอเซิงยังคงมีความสุข ยังคงรู้สึกดีกับความสัมพันธ์ที่มีต่อกัน เพียงแต่ไม่รู้ความจริงทั้งหมดเบื้องหลังเท่านั้นเอง

*มันแค่การฝึกฝน* เขาบอกกับตัวเองเงียบๆ เหมือนที่เคยบอกตัวเองมาตลอดตั้งแต่เริ่มทดลองกับชาวบ้านทั่วไปในหมู่บ้านนับตั้งแต่วันที่ควบคุมพลังงานโลกเซียนภายนอกร่างกายได้สำเร็จ

การทดลองกับเด็กที่ร้องไห้ การระงับปากเสียงชาวบ้านที่ทะเลาะกัน ล้วนเป็นก้าวเล็กๆ ที่นำมาสู่ความสามารถในการควบคุมสถานการณ์ซับซ้อนขึ้นแบบที่กำลังทำอยู่กับเหอเซิงตอนนี้ ทุกอย่างล้วนเป็นส่วนหนึ่งของกระบวนการฝึกฝนที่เขายอมรับได้ในใจโดยไม่มีข้อกังขา

"ทำเสร็จแล้ว" เสี่ยวเป่าพูดขึ้นมาด้วยความภูมิใจ ยกกิ่งไม้ที่ต่อเป็นรูปคล้ายกระต่ายขึ้นให้ดู

เฉินมู่หันมองแล้วยิ้มจริงใจ "เก่งมาก"

รอยยิ้มนั้นไม่ได้ปรุงแต่งเลยแม้แต่น้อย ความรักที่เขามีต่อเสี่ยวเป่ายังคงบริสุทธิ์เหมือนเดิมทุกประการ ไม่ปนเปื้อนกับสิ่งที่กำลังเกิดขึ้นกับเหอเซิงเลยแม้แต่น้อย เป็นสองด้านที่แยกออกจากกันอย่างชัดเจนในใจของเขา

*เจ้าดูมีความสุขนะวันนี้* เหอเซิงพูดขึ้น สังเกตเห็นรอยยิ้มที่เฉินมู่มีให้เสี่ยวเป่า

*เสี่ยวเป่าเป็นเหมือนน้องคนหนึ่งของข้า* เฉินมู่ตอบตามความจริง *ทุกอย่างที่ทำเพื่อเสี่ยวเป่า ข้าทำด้วยใจจริงเสมอ*

เหอเซิงรู้สึกอบอุ่นไปกับคำตอบนั้น ไม่รู้เลยว่าความจริงใจที่เฉินมู่มีต่อเสี่ยวเป่านั้น ต่างออกไปอย่างสิ้นเชิงจากสิ่งที่กำลังเกิดขึ้นกับตัวเหอเซิงเอง

บทสนทนาดำเนินต่อไปเรื่อยๆ ท่ามกลางบรรยากาศสงบของยามเช้า เหอเซิงยังคงไม่รู้ตัวเลยแม้แต่น้อยว่าความไว้วางใจที่มอบให้เฉินมู่อย่างเต็มที่นั้น ส่วนหนึ่งไม่ได้เกิดขึ้นจากการตัดสินใจอย่างอิสระของตัวเองเลย แต่เป็นผลจากพลังจิตที่แทรกซึมอยู่เบื้องหลังทุกช่วงเวลาที่ทั้งสองได้พูดคุยกันมาตลอดสิบสามวันนี้
