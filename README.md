# เถียนเสวียนลู่ — เส้นทางสู่ฟ้าเถื่อน

นิยายเซียนเซี่ย (Xianxia) ภาษาไทย เขียนแบบทยอยเป็นตอน

## โครงสร้างโฟลเดอร์

```
Onisoo/
├── story-bible/        เอกสารคุมเรื่อง — เปิดดู/แก้ก่อนเขียนตอนใหม่ทุกครั้ง
│   ├── writing-rules.md กฎเหล็กการเขียน — ต้องยึดถือทุกตอน ห้ามฝ่าฝืน (อ่านก่อนเอกสารอื่น)
│   ├── overview.md      เรื่องย่อ, เดิมพัน, ธีมหลัก, ปมที่ต้องเฉลย
│   ├── characters/      ตัวละครแต่ละคน แยกไฟล์ต่อคน + index.md เป็นดัชนีรวม
│   ├── world.md         ระบบขั้นบันไดการฝึก, กฎของโลก, ภูมิศาสตร์
│   ├── timeline.md      เหตุการณ์เรียงตามเวลาในเรื่อง
│   └── glossary.md      คลังคำศัพท์เฉพาะ (ชื่อคน/สถานที่/วิชา) กันสะกดเพี้ยน
├── chapters/            เนื้อหานิยายแต่ละตอน (001-xxx.md, 002-xxx.md, ...)
└── chapter-log.md       สรุปท้ายตอนสั้นๆ ของทุกตอนที่เขียนแล้ว
```

## วิธีใช้

- ก่อนเขียนตอนใหม่: เช็ค `story-bible/characters/` (ระดับพลังล่าสุดของแต่ละตัวละคร ผ่าน `index.md`) และ `story-bible/timeline.md` (เหตุการณ์ล่าสุด)
- เขียนตอนใหม่ลงใน `chapters/` ตั้งชื่อไฟล์แบบ `NNN-ชื่อตอน.md`
- หลังเขียนจบตอน: อัปเดต `chapter-log.md`, `story-bible/timeline.md` และไฟล์ตัวละครที่เกี่ยวข้องใน `story-bible/characters/` (ถ้ามีการเปลี่ยนแปลง)
- เพิ่มตัวละครใหม่: สร้างไฟล์ใหม่ใน `story-bible/characters/` แล้วเพิ่มแถวใน `characters/index.md`
- ถ้ามีชื่อเฉพาะใหม่ (คน/สถานที่/วิชา) ให้เพิ่มลง `story-bible/glossary.md` ทันที
