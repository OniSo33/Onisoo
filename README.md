# เถียนเสวียนลู่ — เส้นทางสู่ฟ้าเถื่อน

นิยายเซียนเซี่ย (Xianxia) ภาษาไทย เขียนแบบทยอยเป็นตอน

## โครงสร้างโฟลเดอร์

```
Onisoo/
├── story-bible/        เอกสารคุมเรื่อง — เปิดดู/แก้ก่อนเขียนตอนใหม่ทุกครั้ง
│   ├── writing-rules.md กฎเหล็กการเขียน — ต้องยึดถือทุกตอน ห้ามฝ่าฝืน (อ่านก่อนเอกสารอื่น)
│   ├── overview.md      เรื่องย่อ, เดิมพัน, ธีมหลัก, ปมที่ต้องเฉลย
│   ├── characters/      ตัวละครแต่ละคน แยกไฟล์ต่อคน + index.md เป็นดัชนีรวม
│   ├── world.md         ระบบขั้นบันไดการฝึก, กฎของโลก, ภูมิศาสตร์
│   ├── timeline.md      เหตุการณ์เรียงตามเวลาในเรื่อง
│   └── glossary.md      คลังคำศัพท์เฉพาะ (ชื่อคน/สถานที่/วิชา) กันสะกดเพี้ยน
├── chapters/            เนื้อหานิยายแต่ละตอน (0000-บทนำ-xxx.md เป็นบทนำ, 0001-xxx.md เป็นตอนที่ 1, 0002-xxx.md เป็นตอนที่ 2, ...)
└── chapter-log.md       สรุปท้ายตอนสั้นๆ ของทุกตอนที่เขียนแล้ว พร้อมลิงก์ — ใช้เป็นสารบัญหลักได้เลย
```

## วิธีใช้

- ก่อนเขียนตอนใหม่: เช็ค `story-bible/characters/` (ระดับพลังล่าสุดของแต่ละตัวละคร ผ่าน `index.md`) และ `story-bible/timeline.md` (เหตุการณ์ล่าสุด)
- เขียนตอนใหม่ลงใน `chapters/` ตั้งชื่อไฟล์แบบ `NNNN-ชื่อตอน.md` — **เลข 4 หลักเสมอ** (0001, 0002, ..., 2000+) เรียงลำดับถูกต้องแม้ไฟล์จะเยอะมาก
- หัวข้อ (H1) ในไฟล์ตอน ให้ใช้รูปแบบ **`ตอนที่ N: ชื่อตอนว่า [ชื่อตอน]`** เสมอ (บทนำใช้ `บทนำ: [ชื่อตอน]`) — ให้ตรงกันทุกตอนทั้งในไฟล์ตอนและใน `chapter-log.md`
- หลังเขียนจบตอน: อัปเดต `chapter-log.md` (พร้อมลิงก์ไปตอนนั้น), `story-bible/timeline.md` และไฟล์ตัวละครที่เกี่ยวข้องใน `story-bible/characters/` (ถ้ามีการเปลี่ยนแปลง)
- เพิ่มตัวละครใหม่: สร้างไฟล์ใหม่ใน `story-bible/characters/` แล้วเพิ่มแถวใน `characters/index.md`
- ถ้ามีชื่อเฉพาะใหม่ (คน/สถานที่/วิชา) ให้เพิ่มลง `story-bible/glossary.md` ทันที

## เมื่อเรื่องยาวขึ้นมาก (หลักร้อย/หลักพันตอน)

โครงสร้างนี้ออกแบบให้รองรับได้ถึงหลักพันตอนโดยไม่ต้องเปลี่ยนระบบ:

- **`chapters/` เป็นโฟลเดอร์เดียว ไม่แยกย่อย** จนกว่าจะมีเหตุผลจริง — เมื่อไหร่ที่เนื้อเรื่องแบ่ง "เล่ม/ภาค" ชัดเจนแล้ว (ดู "อาร์กเรื่อง" ใน `overview.md`) จะย้ายไฟล์เข้าโฟลเดอร์ย่อยตามเล่ม เช่น `chapters/เล่ม01-.../0001-xxx.md` — แต่จะทำก็ต่อเมื่อรู้ขอบเขตอาร์กจริงแล้วเท่านั้น ไม่กะเดาล่วงหน้า
- **`chapter-log.md` คือสารบัญหลัก** ไม่ต้องไล่เปิดทีละไฟล์เพื่อดูว่าตอนไหนมีอะไรบ้าง — เปิดไฟล์นี้ไฟล์เดียวพอ
- **`story-bible/characters/index.md`** ทำหน้าที่เดียวกันสำหรับตัวละคร — ถ้าตัวละครเยอะขึ้นมาก ค่อยแบ่ง index เป็นหมวด (ตัวเอก/ตัวร้าย/ตัวประกอบ) ทีหลังได้
- ขนาดไฟล์รวมของนิยายเป็นพันตอนก็ยังเล็กมากเทียบกับขีดจำกัดของ GitHub (ดูรายละเอียดที่เคยคุยกันไว้ก่อนหน้า) จึงไม่ต้องกังวลเรื่องพื้นที่เก็บข้อมูลเลย
